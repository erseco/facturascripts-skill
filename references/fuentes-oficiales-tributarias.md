# Fuentes oficiales tributarias para IVA, IGIC, facturación y libros registro

Esta referencia reúne enlaces oficiales que los skills deben consultar cuando una respuesta dependa de normativa vigente, criterios fiscales o formatos de libros registro. No sustituye a la revisión de una asesoría fiscal.

## Regla general

Antes de afirmar tipos fiscales, obligaciones formales, plazos o estructura exacta de libros registro:

1. Comprueba la fecha de actualización de la fuente.
2. Prioriza AEAT, Agencia Tributaria Canaria, BOE y BOC.
3. No uses blogs, foros o respuestas antiguas como fuente principal.
4. Indica la fecha de consulta cuando el dato pueda cambiar.
5. Si la operación se va a presentar ante la Administración, exige revisión humana.

## Uso dentro de los skills

Cuando el usuario pida algo como “qué IGIC lleva esto”, “prepara el libro de facturas recibidas”, “calcula IVA deducible” o “esto va a VERI*FACTU”, el skill debe:

1. Preguntar o inferir territorio fiscal solo si el dato está claro.
2. Si no está claro, pedir territorio: Península/Baleares, Canarias, Ceuta/Melilla, UE o terceros países.
3. Consultar estas fuentes si el resultado depende de normativa vigente.
4. Separar datos de FacturaScripts de interpretación fiscal.
5. Indicar incertidumbre y recomendar revisión fiscal cuando proceda.
